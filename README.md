# 🌾 Digital Village Management System (DVMS)

The Digital Village Management System (DVMS) is a full-stack web application designed to digitize and simplify village administration. It provides an online platform for citizens to access government services and enables administrators to manage village data efficiently.

## 🚀 Features
- User Authentication (Login & Registration)
- Role-Based Access (Citizen, Officer, Admin)
- Scheme Management (View & Apply)
- Complaint Submission & Tracking
- Service Request Management
- Announcements System
- Dashboard with insights

## 🛠 Tech Stack
Frontend: React.js, HTML, CSS, JavaScript  
Backend: Java (Spring Boot), REST APIs  
Database: MySQL / PostgreSQL  
Tools: Git, Postman, VS Code / IntelliJ IDEA  

## 📁 Project Structure
Digital-Village-Management-System/

│── dvms-frontend/    
│── dvms-backend/     
│── database/         

## ⚙️ Installation & Setup

### Clone Repository
git clone https://github.com/sabbanimanideep/Digital-Village-Management-System.git
cd Digital-Village-Management-System

### Backend Setup
cd dvms-backend
mvn spring-boot:run

Backend: http://localhost:8080

### Frontend Setup
cd dvms-frontend
npm install
npm run dev

Frontend: http://localhost:5173

## 🔐 User Roles
Citizen → Use services  
Officer → Process requests  
Admin → Manage system
